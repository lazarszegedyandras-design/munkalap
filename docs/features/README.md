# Funkcióspecifikációk

Minden új, több réteget érintő funkcióhoz külön Markdown fájl készüljön ebben a mappában. Tartalmazza a célt, a felhasználói folyamatot, jogosultságokat, adatmodell/API-változásokat, hibás eseteket és elfogadási feltételeket. Az elfogadott változat legyen a Codex implementációjának alapja.
